# wsp-radiology

Radiology models require expert-labeled images,
and a model trained for one task or institution usually needs new labels
before it can be used for another.
This project asks whether a frontier language model can reduce that
labeling requirement by editing the weights of an image model directly,
an approach called [weight-space programming][wsp].
Early reports show that language models can repair specific failures
in small networks.
It is not known whether they can help a model learn a new imaging task
from fewer labeled patients.

We use the language model as an optimizer
that reasons about what the neurons and features of a network compute.
It has interpretability tools, public data and models, and GPU compute,
and it may train models as well as edit them.
The only restriction is the number of expert labels
it receives from the target dataset.

The main comparison is between two agents running Claude Opus 5.5
under the same conditions.
One may write network weights directly, and the other may not.
Both are also compared with conventional label-efficient methods,
including linear probes, fine-tuning, semi-supervised learning,
transfer from public datasets, and labels generated by the language model.
Performance is measured on held-out patients across several label budgets.

To avoid contamination,
we use datasets released after the language model's training cutoff
and block the agents from downloading the target dataset.
The pilot uses a pediatric forearm radiograph dataset
for Monteggia fracture classification.
Later phases will address knee MRI and detection or segmentation tasks.
